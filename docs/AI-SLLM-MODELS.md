# AI-SLLM-MODELS.md — 적용 대상 sLLM 모델 카탈로그

> 작성일: 2026-04-13
> 문서 역할: 본 에이전트 시스템에서 제공할 Small LLM 모델의 후보 리스트, 특성, 선정 이유, 기대 요소 정리

---

## 1. 선정 원칙

| 원칙 | 설명 |
|------|------|
| **한국어 능력 우선** | 한국어 특화 모델 + 한국어를 잘 지원하는 다국어 모델 우선 |
| **동일 모델군 내 다양한 크기** | 가능한 한 1.5B / 3B / 7B 세 단계 제공해 하드웨어별 선택폭 확보 |
| **RPi5 양 환경 지원** | 8GB 환경(~3B 이하) / 16GB 환경(~7-8B) 모두 커버 |
| **ollama 가용성** | 공식 라이브러리 또는 커뮤니티 GGUF(Modelfile 등록)로 ollama에서 pull 가능 |
| **라이선스** | 개인/연구 사용 허용. 상업적 사용 가능 여부는 별도 명시 |
| **2024~2026년 모델 중심** | 최신 훈련 데이터와 아키텍처 반영 모델 우선 |

## 2. 하드웨어 환경별 권장 구성

### 2.1 RPi5 8GB (저사양 환경)

- **모델 크기 제한**: Q4_K_M 양자화 기준 **~3B 이하**
- **모델당 RAM 상한**: 약 4GB (OS + 백엔드와 공존)
- **디스크 상한**: 모델당 2GB 이내
- **권장 모델 수**: 동시 설치 4~5종

### 2.2 RPi5 16GB (표준 환경)

- **모델 크기 제한**: Q4_K_M 양자화 기준 **~8B 이하**
- **모델당 RAM 상한**: 약 6GB
- **디스크 상한**: 모델당 5GB 이내
- **권장 모델 수**: 동시 설치 8~10종

### 2.3 공통

- **양자화**: 기본 Q4_K_M (품질/크기 균형 최적). 필요 시 Q5_K_M(품질 우선) 또는 Q3_K_M(크기 우선) 옵션 제공
- **스왑**: 16GB SWAP 설정 권장 (대형 모델 로딩 시 일시적 여유)

### 3.1 EXAONE 3.5 (LG AI Research)

| 항목 | 값 |
|------|---|
| 개발사 | LG AI Research (한국) |
| 출시 | 2024.12 |
| 제공 크기 | **2.4B**, **7.8B**, 32B(제외 — RPi 한계) |
| ollama 명칭 | `exaone3.5:2.4b`, `exaone3.5:7.8b` |
| 권장 환경 | 2.4B: 8GB+ / 7.8B: 16GB |
| 한국어 능력 | 최상 (한-영 이중언어 학습, 한국어 토크나이저 최적화) |
| 라이선스 | EXAONE AI Model License (연구/비상업 무료, 상업 별도 협의) |

**선정 이유**:
- LG AI Research가 한국어 데이터를 집중 학습한 최신 모델. 한국어 유창성과 정확성이 동급 크기 다국어 모델 대비 월등함
- 동일 모델의 2.4B/7.8B 두 크기로 8GB/16GB 환경 모두 커버

**기대 요소**:
- 일상 대화/지식 질의에서 자연스러운 한국어 응답
- 한국 문화/역사/사회 맥락에 대한 이해도
- 한-영 번역 및 코드 설명의 한국어 표현력

## 4. Tier 2 — 다국어 고성능 모델 (한국어 양호)

### 4.1 Qwen 3 (Alibaba)

| 항목 | 값 |
|------|---|
| 개발사 | Alibaba (중국) |
| 출시 | 2025.04~ |
| 제공 크기 | **0.6B**, **1.7B**, **4B**, **8B**, 14B(제외), 32B(제외) |
| ollama 명칭 | `qwen3:0.6b`, `qwen3:1.7b`, `qwen3:4b`, `qwen3:8b` |
| 권장 환경 | 0.6B~4B: 8GB / 8B: 16GB |
| 한국어 능력 | 양호 (CJK 강점, 한국어 훈련 데이터 포함) |
| 라이선스 | Apache 2.0 (상업 사용 자유) |

**선정 이유**:
- 동일 모델군이 **0.6B/1.7B/4B/8B** 네 크기로 제공되어 본 프로젝트 요구(1.5B/3B/7B 라인업)에 가장 완벽하게 부합
- Apache 2.0 라이선스로 상업/배포 제약 없음
- CJK(중국어/일본어/한국어) 통합 학습으로 한국어 품질이 다국어 모델 중 최상위권

**기대 요소**:
- 동일 모델군 크기별 성능 체감 비교 (사용자가 크기 선택의 trade-off 체험)
- 한자 기반 개념어/전문 용어 번역/설명 강점
- Thinking Mode(추론 모드) 지원 — 에이전트 추론 확장에 활용 가능

| 항목 | 값 |
|------|---|
| 개발사 | Google DeepMind |
| 출시 | 2026년 (Gemma 3 후속) |
| 제공 크기 | **1B**, **4B**, 12B, 27B (Gemma 3 라인업 계승 예상) |
| ollama 명칭 | `gemma4:1b`, `gemma4:4b` (ollama 등록 확인 후 적용) |
| 권장 환경 | 1B/4B: 8GB+ |
| 한국어 능력 | 양호~상 (Gemma 3 대비 다국어/한국어 개선 기대) |
| 라이선스 | Gemma License |

**선정 이유**:
- Gemma 3의 직속 후속. 훈련 데이터 확장 및 다국어(한국어 포함) 능력 개선 기대
- Google의 최신 아키텍처/훈련 기법 반영으로 동일 크기 대비 성능 향상 예상
- Gemma 3와의 직접 비교로 "모델 세대 교체에 따른 사용자 체감 변화" 평가 가능

**기대 요소**:
- Gemma 3 대비 한국어 자연스러움 개선
- 더 긴 컨텍스트 윈도우 (128K+ 예상)
- 경량(1B/4B) 라인의 품질 강화

**주의**: 2026-04 시점에 ollama 공식 등록 여부 확인 필요. 등록 전이라면 HuggingFace GGUF 다운로드 후 Modelfile로 등록하는 방식 사용.

## 7. 단계별 적용 계획

### Phase A (초기): 최소 기본 세트 (RPi5 8GB/16GB 공통)

**필수 3종**:
1. `exaone3.5:2.4b` — 한국어 기본 체험
2. `qwen3:1.7b` — 경량 다국어
3. `gemma3:1b` — 초경량 빠른 응답

→ 사용자는 이 3종만으로도 전체 체험 가능. 디스크 < 4GB.

### Phase B (확장): 한국어 특화 집중

**추가 3종**:
4. HyperCLOVA X SEED 1.5B (커뮤니티 등록)
5. EXAONE Deep 2.4B (추론 모드)
6. Kanana Nano 2.1B (커뮤니티 등록)

→ 한국어 모델 비교 집합 완성. 디스크 < 10GB.

### Phase C (고성능 - 16GB 전용): 7B 급 추가

**추가 3종**:
7. `exaone3.5:7.8b`
8. `qwen3:8b`
9. `mistral:7b-instruct` 또는 Kanana 8B

→ 대형 모델 체험. 16GB 환경 전용. 디스크 < 25GB.

### Phase D (확장): Gemma 4 / 최신 / 특수

**추가**:
10. `gemma4:1b`, `gemma4:4b` (출시/ollama 등록 시)
11. Phi-4 Mini 3.8B
12. SmolLM2 1.7B (하한선 비교)

## 8. 모델 전환/옵션 UX 기대 요소

본 시스템이 에이전트 채팅 플랫폼이므로, 모델 리스트가 단순 목록이 아닌 **사용자 선택 경험**의 핵심임:

| UX 요소 | 구현 기대 |
|---------|-----------|
| **한국어 적합도 아이콘** | ★ 5단계 표시로 직관적 선택 |
| **하드웨어 적합성 뱃지** | "8GB OK" / "16GB 필요" 표시 |
| **모델 카드** | 각 모델 선택 시 특징/기대 요소/예시 응답 표시 |
| **추천 모델 강조** | 첫 사용자에게 EXAONE 3.5 2.4B 기본 제시 |
| **비교 모드** | 동일 질문을 2~3개 모델에 동시 전송해 응답 비교 |
| **추론 모드 토글** | EXAONE Deep, Qwen 3 thinking 모드 활용 |
| **크기별 스위치** | "같은 모델 작은/큰 버전" 원클릭 전환 (Qwen 3 0.6B↔1.7B↔4B↔8B) |
